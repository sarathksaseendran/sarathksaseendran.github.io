# Sarath K's Portfolio

A professional, responsive portfolio website showcasing my skills, experience, and projects as a Mobile Application Developer.

## 🚀 Live Demo
You can view the live website at [sarathksaseendran.github.io](https://sarathksaseendran.github.io/)

## 📱 Features
- **Responsive Design**: Optimized for mobile, tablet, and desktop screens.
- **Project Showcase**: Links to live apps on Google Play Store and Apple App Store.
- **Skills Visualization**: Interactive progress bars highlighting proficiency in various technologies.
- **Smooth Animations**: Powered by ScrollReveal for a modern user experience.
- **Contact Form**: Integrated with Formspree for direct communication.

## 🛠️ Technologies Used
- **Frontend**: HTML5, CSS3 (with SCSS), JavaScript.
- **Icons**: [Boxicons](https://boxicons.com/)
- **Animations**: [ScrollReveal](https://scrollrevealjs.org/)
- **Forms**: [Formspree](https://formspree.io/)

## 🔧 Installation & Usage
To run this project locally, simply clone the repository and open `index.html` in your preferred web browser.

```bash
# Clone the repository
git clone https://github.com/sarathksaseendran/sarathksaseendran.github.io.git

# Navigate to the project directory
cd sarathksaseendran.github.io

# Open index.html (macOS example)
open index.html
```
